# Product Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task in the current checkout.

**Goal:** Deliver an administrable product catalogue with categories, prices in integer cents, validated product images, and a searchable/paginated public storefront.

**Architecture:** Keep catalogue writes behind the existing admin boundary and expose only active, non-deleted categories/products publicly. Use typed status enums, Eloquent soft deletion, immutable integer-cent prices, server-generated image paths, and Livewire pages for admin and customer interactions.

**Tech Stack:** Laravel 12, PHP 8.4, Eloquent/MySQL, Livewire 3, Tailwind CSS, PHPUnit

**Spec:** `docs/superpowers/specs/2026-09-28-ecommerce-system-design.md`

## Constraints

- Only administrators may create, edit, deactivate, delete, or restore catalogue records.
- Public queries must never expose inactive or soft-deleted records.
- Prices are non-negative integer cents; never use floating-point persistence.
- SKU and slug are unique and normalized server-side.
- Image names/paths are generated by the server; validate content MIME, extension, and size.
- Uploaded files live on the configured public disk and are deleted when their image record is removed.
- Product records with future inventory/order references will use deactivation/soft deletion rather than destructive cascades.
