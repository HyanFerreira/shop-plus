# Figtree for login and registration

Only the login and registration routes use this delivery; storefront and recovery pages keep their original delivery.

These unmodified WOFF2 files are the exact Figtree files previously delivered to this project by Bunny Fonts. The SIL Open Font License 1.1 and copyright notice are included in OFL.txt. Upstream: https://github.com/erikdkennedy/figtree ; license source: https://github.com/google/fonts/blob/main/ofl/figtree/OFL.txt .

Only normal weights 400, 500, 600 and 700 are included. Latin and Latin Extended subsets retain their original Unicode ranges. Initial auth content uses Latin 400/600/700 (34,304 bytes total); 500 is needed for validation messages, and extended subsets load only when corresponding glyphs are used. Preload includes 500 only for server-rendered errors. No synthetic weight, font conversion or subsetting was introduced.

Original download URLs and checksums are in sources.json. Internal font names such as Figtree Light are those of the original binaries; the CSS family remains Figtree.
